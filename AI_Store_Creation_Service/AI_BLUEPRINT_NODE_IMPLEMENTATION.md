# AI Blueprint Node Implementation

Implemented components:

- Provider-backed Blueprint generation using `BLUEPRINT_PROMPT`.
- Explicit StoreBlueprint JSON contract injected into provider messages.
- New provider methods:
  - `generate_store_blueprint`
  - `repair_store_blueprint`
- Structural and locked-constraint validation through `validate_store_blueprint`.
- Bounded AI repair loop with a maximum of three repair attempts.
- JSON parsing failures are also routed through Blueprint repair.
- Blueprint node stores repair counters and validation status in graph state.
- LangGraph integration:
  - Decide -> Blueprint -> Generate
  - Blueprint failure -> Recoverable Failure
- Generation now consumes the validated AI Blueprint instead of rebuilding a lightweight backend context.

The backend remains responsible only for schema, locked constraints, counters, routing, and safe failure handling. Strategic Blueprint content is generated by the AI.
